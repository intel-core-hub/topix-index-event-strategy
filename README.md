# topix-index-event-strategy

TOPIX第2段階改革の移行措置（段階的ウエイト低減）を狙う指数需給イベント戦略の検証プロジェクト。

初回本試験: **2026-10-30(金)**（10月最終営業日 = 初回定期入替の実施日）

## 現状（2026-09-12時点）

予行演習（第1段階 第8〜10回の再検証）は未実施。以下の設計変更を経て、これから実行するところ。

### 判明した問題と対応

1. **売買方向の疑義** — 現行ルール `D-1引け買い→D引け売り` は、日本証券経済研究所の分析
   （第1段階初回 2022-10-28 の実施日分析）によれば **下落を受ける側**（実施日引けで平均▲1.58%、
   その後13営業日で回復）。方向を再検証する必要がある。詳細: `W1_方向の判明と設計変更.md`

2. **J-Quants無料プランの制約** — TOPIX指数データ取得不可（→ 1306 ETFで代替）、
   データ期間は直近2年12週まで（→ 第8〜10回の3イベントのみ利用可、第1〜7回は範囲外）。
   詳細: `W1_データ制約と穴埋め.md`

3. **サンプル数の限界** — 現行のヘッジ設計（1356ベア2倍ETF）では必要イベント数が約26件になり、
   全10回のうちの3件では構造的に検出不可能。**対照群マッチ方式**（同規模区分・同業種の
   非対象銘柄の等加重を差し引く）に変更することで、必要イベント数を3〜4件まで下げた。

## ファイル

| ファイル | 内容 |
|---|---|
| `event_windows.py` | 予行演習の本体。第8〜10回について複数の保有窓×2種類の推定量(ETF基準/対照群マッチ)で相対効果とS/Nを算出 |
| `P1_逆算スケジュール.md` | 10/30本番からの逆算スケジュールと3本の撤退ライン |
| `W1_方向の判明と設計変更.md` | 売買方向の検証結果と保有窓設計の変更理由 |
| `W1_データ制約と穴埋め.md` | J-Quants無料プランの制約と対応、対照群マッチの設計根拠 |
| `targets_example.csv` | 対象銘柄コードCSVのフォーマット例（実データは要作成） |

## 実行方法

```bash
export JQUANTS_REFRESH_TOKEN="..."
python event_windows.py --targets targets.csv
```

`targets.csv` は JPX「第1段階の見直し」の**2023-10-06再評価後リスト**から作成する（未作成）。
